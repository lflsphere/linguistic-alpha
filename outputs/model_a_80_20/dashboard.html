Model definitions

  • Zero and training-mean prediction benchmarks.
  • OLS on controls; OLS with GICS sub-industry and year fixed effects.
  • Ridge with sub-industry/year effects (alpha=10, fixed in advance).
  • Random forest and extremely randomized trees using the same standard controls.

The OLS coefficient table is fit on training data only; standard errors are clustered by PERMNO. They do not account for common quarter shocks, so coefficient p-values are exploratory. No transcript text or language features enter Model A. This is a research prototype, not a capacity-aware execution backtest.
