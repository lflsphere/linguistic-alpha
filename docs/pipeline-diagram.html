Key joins: CIQ companyid → gvkey → permno → IBES ticker. All date-validated: link must be active on the call date.
SUE: Uses unadjusted IBES with CRSP cumulative factor adjustment for splits between consensus and announcement dates.
Day 0: Call before 4pm ET on a trading day → same day. After 4pm → next trading day. CAR[2,20] is the primary target.
Resumable: Each parquet is skipped if it exists. Interrupted runs resume where they stopped.
