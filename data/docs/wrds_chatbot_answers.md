## Team decisions (2026-11-17)

- Data are pulled from **2008-01-01** for every table. Sample = **2011 Q1 – 2026 Q3, 63 quarters** (build 2011–2023, 52 quarters; holdout 2024 Q1 – 2026 Q3, 11 quarters). Events start on **2011-01-01**, when transcript coverage by the Day 0 close first passes 90% (93% in 2011 Q1 vs. 41–67% in 2010); 2008–10 feed lookbacks only (`docs/pipeline.md`, Sample period).
- Transcripts (Q15, Q16, revised): text = the **latest version created by the close of Day 0** (ordered by `transcriptcreationdate_utc` + `transcriptcreationtime_utc`, never by `transcriptid`); calls with no version by then leave the main sample. Robustness: the earliest version. Every model carries `version_final` (1 = Final / Edited or later, 0 = Preliminary). A version exists by the Day 0 close for 86% of calls overall, 94–99% from 2011 and only 17–52% in 2008–10, so events start on 2011-01-01.
- Market benchmark = S&P 500 total return, `crsp_dsp500_v2.vwretd`; market model on the same index for robustness; CRSP VW market (`indno` 1000200) as an index check; FF4 left for a future risk-management leg (Q4).
